# NORINA Store — Prototype 1

واجهة متجر عربية/إنجليزية متجاوبة مبنية باستخدام HTML/CSS/JavaScript عادي، وتستخدم صور المنتجات الفعلية التي أُرفقت في المحادثة.

## التشغيل
افتح `index.html` في متصفح حديث. لا تحتاج إلى تثبيت حزم.

## ما يعمل في هذه النسخة
- واجهة متجر متجاوبة بالعربية والإنجليزية.
- عرض المنتجين والأسعار المعتمدة.
- سلة مشتريات محلية داخل الصفحة.
- رابط WhatsApp لتجهيز رسالة استفسار عن الطلب.
- عرض صورة تعليمات حمام الجلسرين الأصلية كما وردت.
- روابط الاستفسار عن التوصيل.

## ما لم يُنفذ بعد (لا تستخدم النسخة لاستقبال طلبات حقيقية)
- قاعدة بيانات دائمة وواجهات Backend.
- تسجيل/تسجيل دخول موثّق للعملاء ورموز OTP.
- لوحة إدارة محمية.
- رفع إيصالات التحويل وتخزينها ومراجعتها.
- حفظ الطلبات وأرقامها المرجعية وتتبعها.
- احتساب رسوم التوصيل حسب المنطقة.
- إدارة المخزون والعروض وتجارب العملاء.
- تكامل WhatsApp Business API لإرسال الحملات.
- الاستضافة والنطاق وتهيئة النسخ الاحتياطي.

## المرحلة التقنية التالية
ربط واجهة المتجر بـ Supabase أو Backend مكافئ: جداول العملاء، المنتجات، الصور، الطلبات، عناصر الطلب، عناوين التوصيل، إيصالات الدفع، التجارب، العروض، وموافقات التسويق. يجب تطبيق سياسات صلاحيات على مستوى الصفوف (RLS) والتحقق من الأسعار وحالة الدفع على الخادم. لا تُدرج مفاتيح سرية في ملفات الواجهة.

## الصور
كل الصور في `assets/`، ويمكن استبدالها لاحقاً دون إعادة تصميم الصفحات.
